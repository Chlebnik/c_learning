# Task 1: Hello World

## Goal
Write a program that takes a name as input from standard input and prints "Hello, [Name]!".

## Instructions
1.  Open `hello.c`.
2.  Implement the `main` function.
3.  Use `scanf` to read a string (the name).
4.  Use `printf` to print "Hello, [Name]!\n".
5.  Run `./test_hello.sh` to verify your solution.
