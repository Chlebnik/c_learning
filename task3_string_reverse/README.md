# Task 3: String Reversal

## Goal
Write a program that reverses a string in-place using pointers.

## Instructions
1.  Open `reverse.c`.
2.  Implement the `reverse_string` function.
    *   Use pointers to swap characters from the beginning and end of the string.
    *   Do not use array indexing (e.g., `str[i]`).
3.  Implement the `main` function to read a string, call `reverse_string`, and print the result.
4.  Run `./test_reverse.sh` to verify your solution.
